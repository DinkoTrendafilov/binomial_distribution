Binomial Distribution Visualizer

📊 A Python tool that calculates and visualizes binomial probability distributions
Features

    Takes user input for probability of success (p%) and number of trials (n)

    Computes probabilities for all possible outcomes using the binomial formula:
    P(k) = C(n,k) * pᵏ * (1-p)ⁿ⁻ᵏ

    Sorts results by probability (highest first)

    Generates a clean bar chart with:

        Labeled probabilities (as percentages)

        Mean (red dashed line)

        Standard deviation range (yellow highlight)

Why It Stands Out

✅ Clean, professional visualization (Matplotlib)
✅ Interactive input (no hardcoded values)
✅ Statistical insights (mean, variance, and std. dev. marked)
Usage

    Run the script:
    bash

python binomial_distribution.ipynb

Enter your probability (p%) and trial count (n).

View the generated chart!
